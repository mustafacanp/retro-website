# mustafacanpalaz.com
Windows 95 themed personal website, built with React 18, [React95](https://github.com/React95/React95) and webpack 5.

## Setup

```bash
yarn install   # install dependencies
yarn start     # start dev server
yarn build     # production build (dist/)
```

Content (projects, experience, skills) lives in `src/data/*.json`.
